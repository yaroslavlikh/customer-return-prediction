# Прогнозирование возвращения покупателя

Исследовательский ноутбук по задаче прогнозирования возврата пользователя после заказа на данных соревнования Lamoda. Признаки строятся по истории заказов и товаров; сравниваются LightGBM и CatBoost с подбором параметров Optuna. Для проверки используется разделение по дате и метрика AP для верхних 20% ранжированного списка.

Ноутбук ожидает файлы соревнования `train.csv`, `test.csv`, `orders.parquet`, `products.parquet` и `sample_submission.csv` в рабочей папке. Данные не включены. Для запуска нужны Python, Jupyter, pandas, numpy, scikit-learn, lightgbm, catboost, optuna и движок Parquet (например, pyarrow).

Ноутбук сохранён как исследовательский эксперимент: отдельные ячейки выполнялись последовательно и могут требовать доработки для воспроизведения с нуля.
